▼Update contents implemented on 2024/09/19

○Interaction Feature

We have added an "Interaction" feature where you can enjoy stories with the characters you have welcomed. Through the various interactions between different characters in each interaction story, we hope you will feel the charm of the characters even more.

As the first release, we have prepared stories where you can enjoy "interaction" with Resna as Izana, among others. More characters available for "interaction" will be added in future updates.

〇Difficulty Setting Feature for Main Story Battles

We have added a feature that allows you to set the difficulty of battles in the main story. The difficulty can be selected from "Normal," "Easy," or "Very Easy," and if set to "Easy" or "Very Easy," the status of enemies appearing in battles will be reduced according to each setting.

〇Home Screen Setting Feature

We have added a feature that allows you to set certain scenes unlocked through story progression and other means as your home screen.

※You can still set it to change the home screen according to story progression as before.

We will continue to work hard to develop a good game together with all users, so please continue to support "Atelier Resleriana".
