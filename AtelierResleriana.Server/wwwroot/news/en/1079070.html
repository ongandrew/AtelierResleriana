About the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass

By earning the required amount of Event Mission PT, which are rewards for clearing the event mission "2nd Anniversary ★3 Character Guaranteed Wish Mission", you can obtain various rewards presented in the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass.

The 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass can be used for free, but unlocking Premium requires Paid Lodestar Gems ×3,000.

Additionally, the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass has a sales period, and for rewards from the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass that ended sales, only unclaimed rewards that were obtainable at the time of ending will be sent to "Mail".

※Wish Tickets sent to "Mail" will disappear when the "2nd Anniversary ★3 Character Guaranteed Wish" ends. Therefore, please be sure to use them within the "2nd Anniversary ★3 Character Guaranteed Wish" event period.

※For mission details, please check Home Screen ＞ Mission ＞ Event ＞ 2nd Anniversary ★3 Character Guaranteed Wish Mission.

※Please note that rewards for conditions that were not met cannot be obtained.

About Premium Unlock

When you unlock Premium for the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass, you will be able to obtain the Premium rewards presented in the 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass that is currently on sale at the time of unlocking. The reward contents can be confirmed from Shop ＞ Recommended ＞ 2nd Anniversary ★3 Character Guaranteed Wish Mission Pass ＞ Premium Exchange Confirmation Dialog.

When unlocking Premium, Premium rewards whose acquisition conditions have already been met will become immediately obtainable.

※Before unlocking Premium, please be sure to confirm the Premium reward contents and that the Mission Pass you are purchasing is the "2nd Anniversary ★3 Character Guaranteed Wish Mission Pass".
