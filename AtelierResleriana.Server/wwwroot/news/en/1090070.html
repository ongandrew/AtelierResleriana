"Event Mission Pass [Mysteries and Mechanisms Island]" Now on Sale!

Thank you for always enjoying 'Atelier Resleriana'.

To commemorate the opening of the event "Mysteries and Mechanisms Island," we are selling the Event Mission Pass [Mysteries and Mechanisms Island].

The "Event Mission Pass [Mysteries and Mechanisms Island]" is available at Home > Shop > Recommended tab.

About the Event Mission Pass [Mysteries and Mechanisms Island]

By obtaining the specified amount of Event Mission PT, which are clear rewards for the event "Mysteries and Mechanisms Island Missions," you can obtain various rewards presented in the Event Mission Pass [Mysteries and Mechanisms Island].

There are Regular rewards and Premium rewards, with Premium rewards becoming obtainable by unlocking Premium.

The Event Mission Pass [Mysteries and Mechanisms Island] can be used for free, but unlocking Premium requires Paid Lodestar Gems x500.

Additionally, the Event Mission Pass [Mysteries and Mechanisms Island] has a sales period, and for rewards from the Event Mission Pass [Mysteries and Mechanisms Island] that has ended sales, only unclaimed rewards that were obtainable at the time of termination will be sent to "Mail."

※For mission details, please check Home Screen > Missions > Events > Mysteries and Mechanisms Island.

※Please note that rewards for which acquisition conditions were not met cannot be obtained.

About Premium Unlocking

When you unlock Premium for the Event Mission Pass [Mysteries and Mechanisms Island], you can obtain Premium rewards presented in the Event Mission Pass [Mysteries and Mechanisms Island] that is currently on sale at the time of unlocking. Reward contents can be checked from Shop > Recommended > Event Mission Pass [Mysteries and Mechanisms Island] > Premium Exchange Confirmation Dialog.

When unlocking Premium, Premium rewards for which acquisition conditions have already been met become immediately obtainable.

※Before unlocking Premium, please make sure to check the Premium reward contents and confirm that the Mission Pass you are purchasing is the "Event Mission Pass [Mysteries and Mechanisms Island]" without any mistakes.
