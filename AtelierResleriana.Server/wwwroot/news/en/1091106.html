Issue Where Progress May Become Impossible with Synthesis "Popular Formation"

Thank you for always enjoying "Atelier Resleriana".

We would like to inform you about an issue where progress may become impossible when using "Popular Formation" in synthesis.

Issue Details

On the synthesis recipe selection screen, progress may become impossible when attempting to synthesize using "Popular Formation" (※This issue does not occur when selecting "Easy Synthesis" or "Formation".)

Workaround for the Issue

You can avoid this issue by using either of the following methods:

●On the synthesis preparation screen, proceed to the popular formation screen via "Popular Formation" in the red box shown in the image

●In the custom settings within the Game tab of Home Screen > Menu > Options, set the "Synthesis Effect Skip" option to OFF

Response

We plan to fix this in a future update.

We sincerely apologize for any inconvenience caused.
