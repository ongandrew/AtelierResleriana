Thank you for always enjoying 『Atelier Resleriana』.

We would like to inform you about a bug that may cause progress to halt when using "Popular Formation" in synthesis.

Bug Details

On the synthesis recipe selection screen, progress may halt when attempting to synthesize using "Popular Formation" (※This bug does not occur when selecting "Quick Synthesis" or "Formation".)

How to Work Around the Bug

You can work around the bug using either of the methods below.

●On the synthesis preparation screen, proceed to the popular formation screen from "Popular Formation" in the red frame in the image

●Set the "Skip Synthesis Effects" option to OFF in the custom settings within the game tab of Home Screen > Menu > Options

Response

We plan to fix this in a future update.

We deeply apologize for the inconvenience caused to everyone.
