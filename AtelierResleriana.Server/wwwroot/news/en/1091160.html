How to Play

"The Matchmaker: A Star-Lit Path LEGEND CHALLENGE" is an event where you play high-difficulty battles in score attack format.

There is only one battle you can challenge, and the score evaluation criteria are the same as Score Battles.

Challenge repeatedly and aim for higher scores!

Your obtained scores are displayed in ranking format, with higher rankings earning more rewards.

※This event only has ranking rewards, with no score rewards or clear rewards.

Ranking Rewards

In "The Matchmaker: A Star-Lit Path LEGEND CHALLENGE," you can obtain various rewards based on your ranking position!

Ranking rewards are distributed via "Mail" by logging in after the event period ends.

※When multiple users have the same score, they receive the same ranking.

Example: If there are 3 users with the 10th place score, all 3 users will be ranked 10th, and the next user will be ranked 13th.

You can check the reward details from Event > The Matchmaker: A Star-Lit Path LEGEND CHALLENGE > Ranking > Ranking Reward List.
