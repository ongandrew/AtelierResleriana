About Receiving Rewards

To receive rewards, you need to input your『Atelier Resleriana』User ID within『DEAD OR ALIVE Xtreme Venus Vacation』and clear the required missions. For details, please check the guidance within『DEAD OR ALIVE Xtreme Venus Vacation』 ([9/29 17:00] External link has been added.)

You can check your『Atelier Resleriana』User ID using the following steps:

(1) Go to the menu from the menu button at the top right of the home screen.

(2) Go to Player Information from the Player Information button in the menu.

(3) You can check it from the Player ID at the bottom left of the Player Information screen.
