"Knight Practical Exam ~Additional Exercise~" event now live!

This event features "Score Battle" where you can obtain event-exclusive synthesis materials and recipes, and high-difficulty battles called "Boss Challenge."

This "Score Battle" can be challenged using Stamina instead of challenge tickets. When you clear Score Battle, you can obtain Battle Coins in addition to synthesis materials. Battle Coins can be exchanged for Glimmer of Hope and Lodestar Gems at the exchange shop.

Additionally, clearing the event Boss Challenge will reward you with event-exclusive emblems.

Furthermore, this event introduces the "Event BOX Wish"!

During the event period, clear quests to GET Event BOX Wish Tickets [Knight Practical Exam], then use the Event BOX Wish to obtain rewards like Star Prayer Stone Petals (Memoria)!

Additionally, when you have both Izana [Knight's Beginning] and Johanna [Phenom's Reborn] in your party, Event BOX Wish Tickets [Knight Practical Exam] will drop an additional 5 tickets per character for every 10 Stamina consumed!

※There are no additional drops of "Event BOX Wish Tickets [Knight Practical Exam]" in content that does not consume Stamina, such as Main Story.

Event BOX Wish

Event BOX Wish can be used with "Event BOX Wish Tickets" that can be obtained during the event period.

When you use the Event BOX Wish, you can randomly obtain items from within the BOX.

Each time you use the Event BOX Wish, the contents of the BOX decrease, and when you obtain all items within the BOX, you move on to the next BOX.

You can check the items in each BOX from Event > Knight Practical Exam ~Additional Exercise~ > Event BOX Wish > BOX List.

※The method for obtaining "Event BOX Wish Tickets" may differ by event.

※All BOX contents from BOX 1 onwards are the same.

Rental Party

Event Boss Challenge can be challenged using "Rental Party" with specific characters and memoria already equipped.

You can freely equip Equipment Items and Battle Items created through synthesis to the Rental Party.

Try synthesizing items that match the attribute specialties and roles of the characters in the Rental Party to challenge the Boss Challenge!

※Clear rewards can be obtained even when clearing using Rental Party.

※Characters and memoria equipped in Rental Party cannot be changed. Additionally, the equipped characters and memoria differ by event.

Memoria Bonus

When you clear quests, having bonus-eligible memoria will increase the drop amount of synthesis materials!

Target memoria and bonus amounts can be checked from Event > Knight Practical Exam ~Additional Exercise~ > Score Battle > Memoria Bonus.

※Bonus is added up to a maximum of 200%. Bonus amount increases based on the unlock status of target memoria.

※Simply possessing target memoria will apply the bonus. You don't need to include them in your party.

※When possessing multiple of the same memoria, unlock ranks are combined to increase bonus amount (maximum V)

Example: If you possess 2 target memoria with unlock rank I, it will be calculated as 1 memoria with unlock rank II.
