Regarding Adjustments to Help Descriptions for Forced Break

Regarding the new gimmick "Multiple Break Gauges" that appeared recently, the explanation for using the existing effect "Forced Break" was unclear.

The following changes were made in today's maintenance on 2025/07/11.

▼Changes

●Skill and status effect text changes

○The term "Forced Break" in skill effect description text has been changed to "Reduce one of the target's break gauges to 0"

○The effect description text for status effects with "Forced Break" effects that can be checked during battle has been changed to "Reduce one of the attack target's break gauges to 0"

●Additional descriptions in Battle help

○In the "Break" explanation section, additional explanation has been added for when multiple break gauges are reduced in one attack (When multiple break gauges are reduced to 0 in one attack, the turn order is delayed by the number reduced. For example, if 2 break gauges are reduced to 0 simultaneously, the turn order is delayed more than if only 1 gauge is reduced to 0.)

○An explanation of "Forced Break" has been added to the "Plus Effects/Enhancement Effects" explanation section

※Although the term "Forced Break" remains in some screens as ability effect descriptions and status effect names, the effect is as described in the above changes: "Reduce one of the target's break gauges to 0".

We sincerely apologize for any inconvenience caused to our users.

Please continue to support Atelier Resleriana.
