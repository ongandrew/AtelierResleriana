Ver 2.5.0 Update Completion Notice

The maintenance for the Ver 2.5.0 update has been completed.

The update contents are as follows.

Thank you for your cooperation during the maintenance.

Please continue to enjoy Atelier Resleriana.

Update Contents

●Additional data implementation

●Event Story function improvement

○Improved so that after playing an Event Story, if the next story is playable, it will play continuously

■If the unlock conditions for the next story are not met, or if the next is a battle, continuous playback will end and return to the Event Story list

■After continuous playback ends, first-time rewards for the played Event Stories will be obtained collectively

●Adjustment of some traits

○The effect content and effect values of the following traits have been adjusted

■Fire Blessing

■Ice Blessing

■Bolt Blessing

■Air Blessing

■Slash Blessing

■Strike Blessing

■Stab Blessing

●Help update

○The following help has been updated

■Home (Added descriptions regarding "Home Background Selection")

●Some help screen updates

○Updated some explanatory text on the help screen displayed when first transitioning to the Atelier from the Home screen

●Some shop screen improvements

○Improved the Character Memoria > Lodestar Gem Exchange screen in Home > Shop so that "Lodestar Gem Seed" is displayed in the item icon shown in the upper right of the screen

●"Conversion" improvements

○Improved the limit of items that can be converted at once in "Conversion" from "50" to "100"

○Added "UR and below" as a new option for batch selection

Fixed Bug List

●Bug where the app would force close on some Android devices

○Fixed a bug where the app would force close when entering specific quests or stories on some Android devices

●Bug where Grand Recipes displayed unintendedly on the recipe inspiration reward screen

○Fixed a bug where Grand Recipes added after the maintenance on 2025/07/11 were displayed as "Extra" instead of "Grand" on the Home > Recipe Inspiration > Recipe Inspiration Count screen

●Display bug when obtaining characters with different skins

○Fixed a bug where an unnecessary white icon was displayed in the acquisition dialog when obtaining a character with a different skin from one already owned

●Bug where the Wish button displayed unintendedly after purchasing Lodestar Gem sets with Wish tickets

○Fixed a bug where, on Wish screens that can use any free Lodestar Gems, after purchasing a Lodestar Gem set with Wish tickets that can be used for that Wish, the item display on the Wish button would remain as Lodestar Gems despite owning Wish tickets

●Bug where Event Missions displayed unintendedly under specific conditions

○Fixed a bug where, for various Event Missions displayed in Home > Mission > Event, when switching from a mission list with a scroll bar to one without a scroll bar, the mission display position would become unintended

●Bug with equipment item "Sapientia Annulus"

○Fixed a bug where the name of equipment item "Sapientia Annulus" was incorrect
