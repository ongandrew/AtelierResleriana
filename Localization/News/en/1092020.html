List of Fixed Bugs

●Enemy information display bug for enemies with multiple break gauges

○Fixed a bug where for enemies with multiple break gauges, when displaying enemy information and switching break gauge information using the button to the right of the break gauge, the "×2" and "×1" notations on the button would display in duplicate

●Neo Board ability name display bug when unlocking Neo Boards

○Fixed a bug where when unlocking Neo Boards, if a board ability rank increases, the displayed board ability name would show the name of one rank lower instead

●Effect description text display bug for battle items that apply effects after damage

○Fixed a bug where effect description text for battle items that apply effects after damage had inconsistent descriptions for similar effects (※This is only a text correction, no changes to effects. Unified to the correct text shown in the table below.)

Incorrect:

After ○ attribute damage, applies ~

Correct:

Deals ○ attribute damage and applies ~ to target

●Description text display bug for effect application timing in some character and Memoria abilities

○Fixed a bug where description text for some character and Memoria abilities had incorrect timing descriptions like "when attacking" or "after attacking" that differed from when effects were actually applied (※This is only a text correction, no changes to effects.)

●Effect description text display bug for some Memoria and equipment items

○Fixed a bug where some Memoria and equipment items had ability effect descriptions stating "after attacking" or "when attacking" even for abilities that trigger when using skills that only affect allies without attacking enemies or applying status changes (※This is only a text correction, no changes to effects.)

●Skill icon display bug for skills with skill lamps

○Fixed a bug where lamp lighting prediction effects were not playing for skill icons with skill lamps when the lamp would light up during skill use

●Display bug when selecting Viktor【Noble of Unwavering Justice】's Out-Range skill 2 "Fortress"

○Fixed a bug where part of the skill description text would display outside the display area when selecting Viktor【Noble of Unwavering Justice】's Out-Range skill 2 "Fortress"

●Bug causing inability to progress in story recollection under specific conditions

○Fixed a bug where setting continuous playback to ON in story recollection and starting continuous playback from story Chapter 28-10 "Fashion Discussion" would cause inability to progress when story Chapter 28-11 "Let's Review the Flow" finished playing

●Bug where selected attack target changes when switching skills

○Fixed a bug where during battle, after selecting a skill and switching attack targets using the enemy icons at the top of the screen, selecting a different skill would change the attack target

List of Bugs Under Investigation

●[09/29 Update] Bug where camera angle becomes unintended state when editing home screen in "Character Home" feature

○When editing custom scenes in the "Character Home" feature, changing the camera angle and then switching to another character via character change causes the camera angle to become unintended state

●[09/29 Update] Bug preventing switching home screen to event home using home switch button while custom scene is set

○When a custom scene is set as the home screen background and a limited-time event home exists, the home screen cannot be switched to event home using the home switch button on the right side of the home screen

●[09/29 Update] Bug where skills cannot be activated under specific conditions

○During battle, if you select an incapacitated ally as the target for skills that target all allies, that skill cannot be activated (※This phenomenon can be avoided by selecting a character who is not incapacitated on the timeline, etc.)

●[09/29 Update] Display bug when characters with Burst Gauge acquire Burst Panels under specific conditions

○When characters with Burst Gauge acquire Burst Panels while their gauge is at maximum, the Burst Panel acquisition effect does not play

●[09/29 Update] Bug where traits are not displayed on item detail screen during conversion

○When opening the item detail screen during conversion, traits attached to items are not displayed (※Traits will be displayed if you lock the item once on the item detail screen. This bug does not occur in equipment screens and other screens outside of conversion.)

●[09/29 Update] Bug where characters may not display when custom scene is set as home background

○When setting custom scene as home background, sometimes only the background switches and characters are not displayed (※If this bug occurs, characters will be displayed by restarting the app. This bug is scheduled to be fixed in the next update.)

●[09/29 Update] Notification badge display bug in specific content of "DOAXVV Collaboration" event

○Regarding gravure panels in the "DOAXVV Collaboration" event, when missions listed on panels for characters other than Marie Rose are completed, notification badges do not display on the gravure panel icon on the event TOP

●Display bug when Memoria with unlock rank V are sent via mail

○When Memoria with unlock rank V are sent via mail, the unlock rank displays as I on the mail screen (※This is only a display bug on that screen; the Memoria are properly received at unlock rank V.)

●Bug where status change total values are not displayed correctly under specific conditions

○Under the following conditions, status change total values are not displayed correctly

■When unique status changes that increase effect amount by Lv are applied, the Lv 1 effect amount is reflected in the status change total value regardless of the applied Lv

■Effect amounts from status changes that increase damage and critical damage from battle items are added to the status change total value as skill damage and critical damage increases for skills

●Bug where tanned skin Resna【Pretty Summer】from login bonus cannot be batch received under specific conditions

○When you already have regular skin Resna【Pretty Summer】, tanned skin Resna【Pretty Summer】sent to mail via login bonus cannot be batch received (※It is possible to receive them individually using the receive button in the bottom right of each mail.)

●Daily Pass bug on Android devices

○On Android devices, post-payment billing links are not included in Daily Pass

●Movie playback bug on specific Android devices

○On specific Android devices, the following bugs may occur during movie playback

■Poor video quality

■Stuttering occurs

■Audio desync occurs

■App crashes when playing movies repeatedly

●Display bug for receipt status in mail

○Even after receiving characters, Memoria, or character pieces via mail, the display within mail does not switch to received status (※This is only a display bug; rewards are properly received.)

●Behavior bug in specific battles

○In Battle Chapter 1-35 "Emergency Request・3", the app may crash at specific timing (※Lowering screen resolution or 3D rendering resolution may improve this issue.)

●Bug when viewing video ads on specific devices

○On specific devices, the app may crash when viewing video ads under certain environment settings (※Viewing count will not decrease, so please be assured. Lowering screen resolution or 3D rendering resolution may improve this issue.)

We will continue to address other bugs as they are discovered.

We deeply apologize for any inconvenience caused to everyone.
